# Joidy Documentation

Joidy is a self-hosted, gamified PKM system that turns your notes into experience points. Private, open-source (GPL v3), and runs on your own machine.

**Current version:** v1.1.0-beta.7

## Stack

- **Frontend:** SvelteKit 3 + Vite + TypeScript (adapter-node)
- **API:** FastAPI (Python 3.12)
- **AI service:** FastAPI — Gemini, OpenAI, Anthropic, Cohere, Ollama, OpenRouter (+ any OpenAI-compatible endpoint)
- **Database:** PostgreSQL 16 + pgvector (semantic search)
- **Deployment:** Docker Compose
