# Getting Started

## Requirements

- Docker & Docker Compose
- 4GB+ RAM
- (Optional) an AI API key — Gemini is the primary provider; Ollama works fully local with no cloud key

## 1. Install

**One-liner (Linux/macOS):**

```bash
curl -fsSL https://raw.githubusercontent.com/Axel-DaMage/joidy/development/scripts/install.sh | bash
```

**From source:**

```bash
git clone https://github.com/Axel-DaMage/joidy.git
cd joidy
joidy up
```

`joidy up` generates all secrets on first run (`SECRET_KEY`, `INTERNAL_SECRET`, `INTERNAL_API_TOKEN`, `POSTGRES_PASSWORD`, `GRAFANA_ADMIN_PASSWORD`) and starts the full stack: frontend, API, AI service, worker, PostgreSQL, and the backup sidecar.

## 2. Configure

The only variable you **must** set in `.env` is your Obsidian vault path:

```bash
OBSIDIAN_VAULT_PATH=/path/to/your/vault
```

Add `GEMINI_API_KEY` (or any other provider key) to enable AI features. Ollama users need no key — just `OLLAMA_BASE_URL`.

## 3. First run

Open `http://localhost:3000`. The setup wizard (`POST /config/setup`) creates your account — it is loopback-only and enforces a password policy. Frontend binds `127.0.0.1` by default; expose other interfaces via `BIND_ADDR` if needed.

- UI: `http://localhost:3000`
- API docs (Swagger): `http://localhost:8000/docs`

## Useful commands

```bash
joidy status      # stack health
joidy logs        # tail service logs
joidy backup      # manual pg_dump -Fc backup
joidy down        # stop the stack
```

If `3000`/`8000` are taken, `joidy up` automatically falls back to the next port (up to 5 attempts) and writes the choice back to `.env`.
