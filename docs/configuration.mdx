# Configuration

Joidy is configured via `.env` in the repo root (or `~/.config/joidy/.env` for system installs). On first `joidy up`, all secrets are auto-generated if missing — you only need to set `OBSIDIAN_VAULT_PATH` and any AI keys you want.

## Database

| Variable | Default | Description |
|----------|---------|-------------|
| `DATABASE_URL` | `postgresql://joidy:joidy@postgres:5432/joidy` | Postgres 16 + pgvector DSN |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `joidy` | DB credentials — password auto-generated on first run |

⚠️ `POSTGRES_PASSWORD` and `DATABASE_URL` can drift if you rotate one without the other — keep them in sync.

## Networking

| Variable | Default | Description |
|----------|---------|-------------|
| `BIND_ADDR` | `127.0.0.1` | Host interface for published ports. Only `frontend` and `api` publish to the host |
| `FRONTEND_PORT` / `API_PORT` | `3000` / `8000` | Published ports (`joidy up` auto-falls-back up to 5 ports) |
| `CORS_ALLOWED_ORIGINS` | `http://localhost:3000` | Comma-separated origins |
| `TRUSTED_PROXIES` | — | CIDRs whose `X-Forwarded-For` is trusted for rate limiting |

## Auth & internal secrets

| Variable | Description |
|----------|-------------|
| `SECRET_KEY` | JWT signing key (auto-generated) |
| `INTERNAL_SECRET` | Shared secret for API → ai-service (`X-Internal-Secret` header) |
| `INTERNAL_API_TOKEN` | Bearer token for service-to-service calls (e.g. n8n → `/emails`) |

## AI providers

| Variable | Description |
|----------|-------------|
| `GEMINI_API_KEY` | Primary provider |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` | OpenAI or any OpenAI-compatible endpoint |
| `ANTHROPIC_API_KEY` | Claude |
| `COHERE_API_KEY` | Cohere |
| `OPENROUTER_API_KEY` | OpenRouter |
| `OLLAMA_BASE_URL` | Local Ollama — no key needed |
| `LLM_MODEL` / `EMBEDDING_MODEL` / `LLM_MAX_TOKENS` | Model overrides |
| `AI_SERVICE_ENABLED` | Toggle the ai-service container |

## Vault & Obsidian

| Variable | Description |
|----------|-------------|
| `OBSIDIAN_VAULT_PATH` | **Required** — path mounted into the worker (watched for changes) |
| `OBSIDIAN_WEBHOOK_SECRET` | Secret for the bidirectional-sync webhook |

## Integrations

| Prefix | Notes |
|--------|-------|
| `GITHUB_*` | Personal access token / OAuth |
| `GOOGLE_*` | Calendar & Tasks OAuth (`CALENDAR_SYNC_INTERVAL` = worker poll seconds, default 900) |
| `STRAVA_*` / `SPOTIFY_*` | OAuth scaffolding |
| `TELEGRAM_*` | `TELEGRAM_BOT_TOKEN`, webhook secret, allowed user id |

## Backups

| Variable | Default | Description |
|----------|---------|-------------|
| `BACKUP_ENABLED` | `true` | Sidecar profile, on with `joidy up` |
| `BACKUP_SCHEDULE` | `0 3 * * *` | Cron in `USER_TIMEZONE` |
| `BACKUP_RETENTION_DAYS` | `14` | Daily dumps kept |
| `BACKUP_RETENTION_WEEKS` | `4` | Sunday dumps kept |
| `USER_TIMEZONE` | `UTC` | Timezone for schedules |
| `JOIDY_BACKUP_DIR` | `data/backups/` | Dump destination (files written 0600) |

## Power & idle (opt-in)

| Variable | Description |
|----------|-------------|
| `POWER_MANAGEMENT_ENABLED` | Adds `docker-compose.power.yml`, mounts the Docker socket — **grants root-equivalent host access** |
| `DOCKER_GID` | Real `docker` group GID (required by power overlay) |
| `DOCKER_SOCK_PATH` | Socket path override |
| `JOIDY_IDLE_TIMEOUT` | Auto-sleep after N minutes idle (default 15) |

## Other

| Variable | Description |
|----------|-------------|
| `APP_ENV` | `development` / `production` |
| `VAPID_*` | Web-push keys |
| `GRAFANA_ADMIN_PASSWORD` | Monitoring overlay (auto-generated) |
| `N8N_PORT` / `N8N_ENCRYPTION_KEY` | n8n workflow container |
| `JOIDY_ENV_FILE` / `JOIDY_DATA_DIR` | CLI path overrides |
