# API Reference

Base URL: `http://localhost:8000` (FastAPI, interactive docs at `/docs`).

## Authentication

All data/mutation endpoints require a JWT:

```text
Authorization: Bearer <access_token>
```

**Public endpoints** (no JWT): `GET /`, `GET /health`, `GET /health/ready`, `GET /health/cache`, `GET /config/setup-status`, `POST /config/setup` (loopback-only), `/auth/*`, plus the unauthenticated webhooks noted below.

**Other auth schemes:**

| Scheme | Used by |
|--------|---------|
| `?token=<jwt>` | WebSocket `/ws` |
| `OBSIDIAN_WEBHOOK_SECRET` or JWT | `POST /obsidian/webhook` |
| `TELEGRAM_*` secret validation | `POST /telegram/webhook` |
| `Bearer <INTERNAL_API_TOKEN>` | Service-to-service (e.g. n8n → `/emails`) |
| `X-Internal-Secret: <INTERNAL_SECRET>` | API → ai-service (internal) |

**Errors** follow the FastAPI standard: `{"detail": "..."}`. **Pagination** is `skip`/`limit` query params where supported.

## Rate limiting

- 60 req/min for anonymous IPs, 120 req/min for authenticated users
- `X-RateLimit-*` headers on responses
- Client IP taken from `X-Forwarded-For` **only** when the peer is in `TRUSTED_PROXIES`

## Routers

### auth — `/auth`
`POST /auth/register` · `POST /auth/login` (returns `{access_token, token_type}`) · `GET /auth/status`

### notes — `/notes`
`GET /notes/` (skip/limit, filters) · `POST /notes/` · `GET|PUT|DELETE /notes/{id}` · search + backlink endpoints

### tags — `/tags`  ·  folders — `/folders`
CRUD for tags and note folders (`GET /folders/`, `POST /folders/`, `GET|PUT|DELETE /folders/{id}`).

### skills — `/skills`
Skill tree CRUD and XP-per-skill queries.

### gamification — `/gamification`
`GET /gamification/profile` · `GET /gamification/xp-history` · `POST /gamification/pomodoro` — awards **+15 XP**; body takes `minutes` and an idempotent `pomodoro_id`.

### achievements — `/achievements`
`GET /achievements` (catalog + unlocked state, persisted in Postgres) · `POST /achievements/{id}/unlock` — idempotent, catalog is server-side.

### goals — `/goals`
`GET /goals/` · `POST /goals/` · `GET|PUT|DELETE /goals/{id}` · `PATCH /goals/sort` · `GET /goals/execution-queue` · `POST /goals/{id}/fail`

Supports priority ordering, linked real notes, archiving, one-off tasks, rollover / snowball / daily-reset modes, persistent snowball streaks, icon auto-suggestion.

### mood — `/mood`
`POST /mood/` (daily check-in) · `GET /mood/today` · `GET /mood/history` · `GET /mood/stats`

### personal_streaks — `/personal-streaks`
Streak check-in, freeze, and per-category streak queries.

### calendar_tasks — `/calendar/tasks`
CRUD over calendar-sourced tasks: `GET|POST /calendar/tasks` · `GET|PUT|DELETE /calendar/tasks/{id}` · `GET /calendar/tasks/execution-queue` · done-toggle endpoint. Completed tasks award +5 XP (+3 when untimed).

### planning — `/planning`
Day-planning endpoints; `day_fully_planned` awards +15 XP.

### ai — `/ai`
`POST /ai/chat` (AI assistant backing `/ai` page) · `POST /ai/plan-suggest` · classification/summarization endpoints. Proxied to `ai-service` internally.

### emails — `/emails`
Unified Gmail inbox (populated by the n8n workflow): `GET /emails/` · `GET /emails/accounts` · `POST /emails/` — upsert keyed by `account` + `gmail_id` (service token) · `PATCH /emails/{id}` · `DELETE /emails/{id}`.

### telegram — `/telegram`
`POST /telegram/webhook` (unauthenticated, secret-validated — bot commands `/note /goal /checkin /ask /status /help`) · `GET|PUT|DELETE /telegram/` config (JWT). Events stored in `telegram_events`.

### obsidian — `/obsidian`
`POST /obsidian/webhook` — bidirectional sync push from the vault plugin; authenticated by `OBSIDIAN_WEBHOOK_SECRET` or JWT.

### integrations

| Router | State | Notes |
|--------|-------|-------|
| `/integrations/github` | live | OAuth + repo data |
| `/integrations/google` | live | Calendar `GET /calendar/status`, `POST /calendar/sync`, `GET|POST|PUT|DELETE /calendar/events`; Tasks is scaffolded |
| `/integrations/spotify` | scaffold | OAuth flow, no full frontend |
| `/integrations/strava` | scaffold | OAuth flow, no full frontend |

### sync — `/sync`  ·  vault — `/vault`
`GET /sync/status` · vault operations incl. `POST /vault/restore-goals`.

### export — `/export`  ·  upload — `/upload`
Data export; file uploads (JWT, mime-derived extensions, path-sanitized).

### stats — `/stats`  ·  analytics — `/analytics`
`GET /stats/*` aggregates · `GET /analytics/dashboard` · `POST /analytics/track` · `GET /analytics/usage`.

### config — `/config`
`GET /config/setup-status` (public) · `POST /config/setup` (public, loopback-only, password policy) · authenticated config read/write (JWT).

### metrics — `/metrics`
Prometheus scrape endpoint (api + worker expose it).

### push — `/push`
Web-push subscription endpoints; endpoints are SSRF-validated, VAPID-signed.

### system — `/system` (opt-in)
Only registered when `POWER_MANAGEMENT_ENABLED=true`: `GET /system/power/status` · `POST /system/power/sleep` · `POST /system/power/wake` · `POST /system/power/shutdown`.

### websocket — `/ws`
Realtime events; JWT via `?token=` query param.
