# Installation

## One-liner (Linux / macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/Axel-DaMage/joidy/development/scripts/install.sh | bash
```

Installs the `joidy` CLI, clones the stack, generates secrets, and starts services.

## Windows

Native PowerShell installer (uses Docker Desktop):

```powershell
irm https://raw.githubusercontent.com/Axel-DaMage/joidy/development/scripts/install.ps1 | iex
```

WSL2 is fully supported — see the Windows section in the upstream troubleshooting guide for common issues (line endings, Docker integration, paths).

## Package managers

```bash
# Homebrew
brew tap Axel-DaMage/homebrew-tap && brew install joidy

# Arch (AUR)
yay -S joidy
```

System installs keep config in `~/.config/joidy/.env` and data under `~/.local/share/joidy` (AUR). Uninstall removes `~/.local/bin/joidy` plus the config dir — your `data/` (database, backups) is preserved unless you delete it.

## Manual / from source

```bash
git clone https://github.com/Axel-DaMage/joidy.git
cd joidy
cp .env.example .env
# set OBSIDIAN_VAULT_PATH at minimum
joidy up          # or: docker compose up -d
```

First boot takes ~2 min: images build, PostgreSQL initializes, and Alembic migrations run (`make migrate` to apply manually).

## Updating

```bash
joidy pull        # pull latest images + git pull
joidy restart     # rebuild required after pulling source changes
```

## Port conflicts

`joidy up` tries the configured `FRONTEND_PORT`/`API_PORT` and falls back automatically (up to 5 subsequent ports), persisting the winner to `.env`. To pin ports yourself, set them in `.env`.

## Data locations

| Path | Contents |
|------|----------|
| `data/backups/` | Compressed `pg_dump -Fc` dumps (0600) |
| `postgres_data` (volume) | PostgreSQL 16 + pgvector |
| `OBSIDIAN_VAULT_PATH` | Your vault, mounted read-path into the worker |
